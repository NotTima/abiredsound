# ABI Merchant

Веб-приложение для игры **Arena Breakout: Infinite** — распознаёт предметы торговца (Field Merchant) по звуку и показывает, что в грузе, шансы на редкие предметы и окупаемость.

## Как это работает

1. Открываешь сайт в **Chrome** на ПК
2. Нажимаешь «Слушать игру» → выбираешь окно игры
3. Сайт захватывает аудио через `getDisplayMedia`
4. Звук даунсэмплится → NCC-корреляция по 76 шаблонам pickup/drop
5. Определяет предмет → показывает шансы и окупаемость по выбранной карте

## Быстрый старт

```bash
git clone https://github.com/<your-username>/abi-merchant.git
cd abi-merchant
node server.js
# Открыть http://localhost:8080 в Chrome
```

> **Node.js** 18+ требуется. Зависимостей нет — сервер на чистом `http`.


## Архитектура

| Модуль | Роль |
|---|---|
| `main.js` | Оркестратор UI, карты/режимы |
| `m1a0fa4.js` | AudioEngine: захват, AudioWorklet, загрузка шаблонов |
| `m7d35f4.js` | Worker: буфер Int16 16 кГц, NCC-детектор |
| `m600e70.js` | NccDetector, prepareTemplate |
| `m3d35d3.js` | MerchantModel: шансы, EV, окупаемость |
| `model-core.js` | Геометрия груза, summarize |

## API (мок-сервер)

Сервер мокает все эндпоинты — работает автономно, без подключения к `abiear.ru`:

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/session` | `{ok: true}` |
| POST | `/api/login` | `{ok: true}` (любой ключ) |
| GET | `/api/catalog` | Полный каталог из снапшота |
| POST | `/api/finds` | `{ok: true}` |

## Известные ограничения

- **167 из 189 картинок предметов** не выкачаны (нужна живая сессия)
- **engine.wasm** — пустой, NCC работает в JS-фолбэке (медленнее)
- Код обфусцирован — работает, но читать/менять сложно
- Мок-сервер не проверяет ключи

## Лицензия

Код и звуковые ассеты принадлежат автору abiear.ru. Этот репозиторий — учебный проект.
