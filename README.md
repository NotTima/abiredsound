# ABI RedSound

Веб-приложение для игры **Arena Breakout: Infinite** — распознаёт предметы торговца по звуку и показывает, что в грузе, шансы на редкие предметы и окупаемость.

*by Euthanasia // Timaa*

## Как это работает

1. Открываешь сайт в **Chrome/Edge/Firefox** на ПК
2. Нажимаешь «Слушать игру» → выбираешь окно игры
3. Сайт захватывает аудио через `getDisplayMedia`
4. Звук даунсэмплится → NCC-корреляция по 76 шаблонам pickup/drop
5. Определяет предмет → показывает шансы и окупаемость по выбранной карте

## Быстрый старт

```bash
# 1. Запуск локального сервера
npm start
# или: node server.js

# 2. Открыть в Firefox или Chrome
# http://localhost:8080
```

> **Поддержка Firefox**: Полная! В Firefox при нажатии «Слушать игру» выбирается окно игры, а если браузер не отдаёт системный звук напрямую через захват экрана, автоматически запросится доступ к аудиоустройству (Monitor of Built-in Audio / Stereo Mix / микрофон).

## Структура проекта

```
├── server.js              ← Локальный сервер + мок API
├── site/                  ← Всё приложение (статика)
│   ├── index.html         ← Точка входа
│   ├── js/                ← 36 JS-модулей (обфусцированные)
│   ├── css/               ← Стили
│   ├── audio/             ← 76 звуковых шаблонов (.ogg)
│   ├── img/               ← Карты, иконки предметов
│   ├── api/catalog        ← Снапшот каталога (189 предметов)
│   └── vendor/            ← QR-код библиотека
├── HANDOFF.md             ← Подробная документация по архитектуре
└── README.md              ← Этот файл
```

## Архитектура

| Модуль | Роль |
|---|---|
| `main.js` | Оркестратор UI, карты/режимы |
| `m1a0fa4.js` | AudioEngine: захват, AudioWorklet, загрузка шаблонов |
| `m7d35f4.js` | Worker: буфер Int16 16 кГц, NCC-детектор |
| `m600e70.js` | NccDetector, prepareTemplate |
| `m3d35d3.js` | MerchantModel: шансы, EV, окупаемость |
| `model-core.js` | Геометрия груза, summarize |

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/session` | `{ok: true}` |
| POST | `/api/login` | `{ok: true}` (любой ключ) |
| GET | `/api/catalog` | Полный каталог из снапшота |
| POST | `/api/finds` | `{ok: true}` |
